These images show the real Corgi viewer running in an isolated UI-driver PTY.
Accounts and model catalogs are deterministic fixtures; no personal credentials
or live provider requests are used. The captured terminal cells and their colors
were exported to PNG, cropped to the Manage agents card.

- `manage.png`: Active/Hidden groups, drag handles and keyboard actions.
- `editor.png`: agent settings with Save focused.
- `models.png`: model choices with effort beside Edit.
- `effort.png`: effort choices, including the known default.
