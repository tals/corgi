The architecture keeps composition policy in Bun while pane cells stay native. Each presentation draws current UI state and supplies native pane references, rectangles, cursor, and revision receipts. The differ combines existing pane cells with that UI, avoiding the pane-to-ANSI-to-terminal round trip. Exact equality of complete UI bytes and pane geometry skips unchanged UI replay. Native row revisions narrow the work; exact cell comparisons determine output. The differ owns previous displayed graphemes and links and borrows source cells only during synchronous calls. Images, selections, overlaps, unsupported clipping, and failed native compositions retain the complete ANSI fallback. [Composition](../../src/composition.ts), [native differ](../../native/zig/frame_diff.zig).

Positioned row bytes and scalar modes also replace extra JSON encode/decode at the in-process native boundary. Mirrors compare canonical incoming rows, install only changes, and carry cursor/input modes separately. Native mirrors remain lazily allocated and releasable when hidden. Screen observers reuse text until an explicit native revision changes. Wire protocols and saved formats remain unchanged.

Only brittle caches added by this effort were removed: full-UI CompositionCache dependencies/deadlines, captured sidebar PaintPlan callbacks, fragment patching, the associated native patch mode, and received-ANSI passthrough. Active maintenance returns to a simple 16 ms cap with earlier pane/frame deadlines respected. Safe owner-local row/link caches, canonical receipts, native row ownership, exact UI equality, and bounded provider installation discovery remain. Account lists are read separately; unrelated main caches were not removed. The two newly introduced elapsed gates use monotonic time and have rollback/startup/expiry regressions.
